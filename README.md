# Entelechy Workshop · AI Skills

Free skills we use to make working with AI assistants more useful and straightforward.

## Claude & Codex / ChatGPT Work

Shared instruction-based skills for these assistants. How you install or save them depends on the product you use.

### Project Manager Task Report

Get a clear wrap-up when an AI assistant finishes a task: what you wanted, what actually happened, what is blocked, and what to do next. The skill also works for incomplete tasks and handoffs, so a polished response does not hide unfinished work.

[Read the skill](skills/project-manager-task-report/SKILL.md) · [Download the library](https://github.com/EntelechyWorkshop/ai-skills/archive/refs/heads/main.zip)

### Project Manager Review

Check whether the next step moves your project toward its real goal. Catch wasted effort and decide what to do next.

[Read the skill](skills/projectmanagerview/SKILL.md) · [Download](https://entelechyworkshop.com/downloads/project-manager-review.zip)

## Use it

**Shared skill, in a chat:** open the skill above, copy its contents into your AI assistant, and ask it to use this format when finishing tasks. For an ongoing preference, save it in your assistant's instructions where supported. Pasting it into one chat does not enable it everywhere.

**Shared skill, with an assistant that supports skill folders:** download and unzip the library, then install the `skills/project-manager-task-report` folder using that assistant's documented skill installation method. Keep the included license with it.

These are instruction files, with no bundled executable scripts. Research skills use whatever tools your assistant already has available and is authorized to use. Each assistant decides how to load and follow instructions; we do not promise identical results across products.
