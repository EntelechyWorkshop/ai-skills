# School & Activity Sweep

Bring school emails, class updates, and team schedules into one digest. Keep track of dates and things to do.

Written by Muse; reviewed and packaged by Entelechy Workshop. This package has been checked for reusable wording and permissions, but has not been independently executed in Muse.

## Use

Attach `SKILL.md`, `skill.yaml`, and `LICENSE` to Muse and ask it to save them as a reusable skill. Ask it to confirm the saved location. See the [full guide](https://entelechyworkshop.com/downloads/creating-a-skill-for-muse.md).

Start by naming the school and activity sources you want checked. Muse will ask for the relevant setup. You control sign-in, which sources it may use, and any reminder schedule.
