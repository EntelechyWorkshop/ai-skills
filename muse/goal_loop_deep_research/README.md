# Goal Loop: Deep Research

Research a question in rounds, check the evidence, and pressure-test the conclusion. Use for a substantial research question with a defined finish line.

Written by Muse; reviewed and packaged by Entelechy Workshop. The original workflow was tested in Muse by the Workshop's owner. This packaged revision has been checked for consistency, but has not been independently run in Muse.

## Install

Download this folder with `SKILL.md`, `skill.yaml`, and `LICENSE`. Attach it to Muse and ask it to save a reusable skill, confirm the supported location, and read back the saved name and trigger. See [Creating a Skill for Muse](https://entelechyworkshop.com/ai-skills/muse) for the complete steps.

Start with a specific goal, a way to check completion, and a time or effort limit. Say “Use Goal Loop: Deep Research” in your request. Skills do not unlock extra access, guarantee completion, or keep a session running beyond Muse's limits.
