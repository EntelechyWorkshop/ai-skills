# Project Manager Review

Check whether the next step moves your project toward its real goal. Catch wasted effort and decide what to do next.

## Use

Paste `SKILL.md` into your assistant and ask it to save this as a skill. For assistants that support skill folders, keep this folder intact and use their normal installation method. The skill's saved name is `projectmanagerview`.

`SKILL.md` contains the reusable instructions. `agents/openai.yaml` provides Codex's display name and suggested prompt; it is optional for other assistants. Example: “Use Project Manager Review to assess our next step.”
